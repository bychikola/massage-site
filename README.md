# Массаж лица и тела — сайт-визитка

Одностраничный сайт-визитка: услуги и цены, обо мне, форма записи (заявка уходит в WhatsApp), контакты.

## Как открыть

Просто откройте `index.html` в браузере (двойной клик). Интернет нужен только для шрифтов Google.

## Как поменять данные (номер, адрес, соцсети)

Откройте `js/booking.js` — в самом верху объект `CONFIG`. Замените значения, отмеченные комментарием `ЗАМЕНИТЬ`, сохраните файл — сайт обновится.

- `phoneDigits` — номер для WhatsApp, только цифры, без «+» (например, `79261234567`);
- `phoneDisplay` — как номер показывается на сайте.

Тестовые тексты («Обо мне», подзаголовки) ищите в `index.html` по слову `ЗАМЕНИТЬ`.

## Как запустить проверку логики записи

Нужен Node.js. В папке проекта выполните:

```
npm test
```

## Как заменить фото

Замените файлы в папке `img/` (hero.jpg — главное фото, about.jpg — фото в «Обо мне»), сохранив имена.

## Хостинг

Сайт статический — размещается на любом бесплатном хостинге (GitHub Pages, Netlify) простой загрузкой файлов.
