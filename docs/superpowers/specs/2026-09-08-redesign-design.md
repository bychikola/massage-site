# Дизайн-документ: редизайн сайта «Массаж лица и тела» — направление «Утончённая элегантность»

**Дата:** 2026-09-08
**Статус:** согласован с заказчиком (интерактивные мокапы в `.superpowers/brainstorm/`, выбор: направление A, поток A, богатые анимации)
**База:** дизайн-документ `2026-09-03-massage-site-design.md` (структура, контент, форма — без изменений)

---

## 1. Цель и контекст

Освежить визуальный стиль существующего сайта: сделать его современнее, «дороже» и живее, сохранив текущую концепцию — спа-палитра (золото + тёмный бирюзовый + крем), серif-заголовки, рукописный слоган, золотые рамки, декоративный лист. Мобильная адаптация должна стать безупречной.

**Содержание, прайс, логика формы → WhatsApp, якоря, SEO-меты — НЕ меняются.**

## 2. Итоговые решения (из обсуждения)

1. **Направление A «Утончённая элегантность»** — палитра сохраняется, модернизация через воздух, градиенты, тонкие линии, мягкие тени и деликатные детали.
2. **Поток секций — вариант A:** шапка кремовая полупрозрачная (была золотая); контакты на кремовом фоне (были золотые — сливались с секцией записи); hero — кремовый фон с градиентом; двойные рамки фото; остальное по мелочи.
3. **Анимации — богатые** (см. §6), но с уважением к `prefers-reduced-motion` и производительности на мобильных.
4. **Фото остаются стоковые** — реальные появятся позже, заменяются без перевёрстки.
5. **Шрифт заголовков: New Standard (локальный OTF) вместо Playfair Display** (см. §4).

## 4. Типографика

**Замена шрифта заголовков: Playfair Display → New Standard.**

- Файл `newstandard.otf` (автор А. Крюков, кириллица полная) перемещается из корня в `fonts/newstandard.otf`; подключение `@font-face` в `css/style.css`: `font-display: swap; font-weight: 400; font-style: normal; format("opentype")`.
- Стек: `"New Standard", Georgia, "Times New Roman", serif`.
- Google Fonts: **убрать Playfair Display** из ссылки; остаются Great Vibes и Montserrat (400/500/600).
- В файле только Regular (400): все заголовки набираются `font-weight: 400` с капсом и разрядкой — **запрет синтетического жирного** (font-synthesis: none). Акценты — размером, цветом и разрядкой, а не жирностью. Исключение: цена на карточке остаётся крупной (18–26px) и выделяется золотом.
- Знак рубля «₽»: в New Standard отсутствует — браузер автоматически берёт его из Georgia (следующий в стеке, символ есть). Специальной разметки не требуется. Проверить визуально на скриншотах.
- Скрипт-акценты (слоган hero, лид «Обо мне») — Great Vibes, как сейчас.

## 5. Дизайн по секциям

### 5.1 Шапка (sticky)
- Кремовая полупрозрачная, золотая линия снизу; при прокрутке >8px — мягкая тень `0 4px 20px rgba(3,54,49,.10)` и лёгкое уплотнение (padding-block меньше).
- Логотип и навигация — как сейчас (New Standard, тёмный бирюзовый).
- Мобильное меню — шторка справа с затемнением-оверлеем (полупрозрачный тёмный слой, клик по нему закрывает), пункты крупнее, кнопка «Записаться» внизу шторки. Сохранить текущую логику (inert, aria-expanded, Esc, закрытие по клику).

### 5.2 Hero
- Фон секции: `--grad-hero-bg` (крем → тёплый).
- Панель: `--grad-teal`, декоративные тонкие золотые окружности (2 кольца `border: 1px solid rgba(207,172,88,.25/.18)`) в правом верхнем углу, заголовок/слоган/делитель/текст/кнопки как сейчас, делитель — золотая линия с прозрачным хвостом.
- Фото: рамка `--grad-gold-frame` + внутренняя белая линия `inset: 5px` (двойная рамка).
- Лист: остаётся, с параллаксом при скролле (см. §6).
- Плавающие золотые частицы: 6–8 точек (радиальный градиент золота, 4–7px), генерируются JS-ом в контейнер hero.

### 5.3 Услуги
- Заголовки групп «Массаж тела/лица» — с золотой линией-градиентом под текстом (вместо текущей сплошной).
- Карточки: белые, радиус 16px, мягкая тень; hover: подъём −6px + тень `--shadow-card`, сверху проявляется золотая линия-градиент (2.5px); пилюля «Записаться» — при hover заливается бирюзовым.
- Цена «докручивается» от 0 до значения при первом появлении карточки (1.1s, ease-out cubic).
- Каскадное появление карточек: задержка `i * 0.06s`, максимум 0.5s.

### 5.4 Обо мне
- Фон остаётся бирюзовым (`--grad-teal` допустим), фото в золотой градиентной рамке с двойной линией, скрипт-лид золотом, тексты как сейчас. Больше воздуха (gap).

### 5.5 Запись
- Фон золотой (как сейчас). Форма — белая карточка радиус 20px с тенью `--shadow-hero`.
- Поля: кремовый фон, бордер `1.5px rgba(4,78,71,.16)`, при фокусе бордер teal + кольцо `0 0 0 3px rgba(4,78,71,.14)`. Лейблы — капс 8.5–13px.
- Кнопка отправки — `--grad-gold-btn`, крупная, на всю ширину формы. Кнопки «Позвонить» / «WhatsApp» — `--grad-teal`.
- Фолбэк «скопировать текст» и подсказка цены — без изменений (логика из `js/booking.js`/`main.js`).

### 5.6 Контакты
- Фон меняется на кремовый. Карточки: белые, радиус 16, иконка в круге (`rgba(4,78,71,.08)`), hover-подъём −5px. Соцкнопки — тёмно-бирюзовые круги с золотой иконкой (как сейчас).

### 5.7 Подвал
- Тёмный бирюзовый, бренд золотом — как сейчас; только типографика на New Standard.

## 6. Система движения

Все анимации — только `transform` и `opacity` (исключение: цвет/тень/фон при hover), без layout-анимаций.

| Эффект | Где | Реализация |
|---|---|---|
| Появление секций | `.reveal` | IntersectionObserver (уже есть), плавнее: `.9s ease` |
| Каскад карточек | услуги | задержка по индексу, `.8s ease` |
| Докрутка цены | карточки услуг | JS, rAF, 1.1s cubic ease-out, запуск при появлении |
| Плавающие частицы | hero | 6–8 span-точек, CSS `@keyframes float` (translateY/X + opacity), 9–13s, задержки вразнобой |
| Параллакс листа | hero | JS по scroll (rAF, throttle): лист сдвигается медленнее прокрутки (≈0.2), без `will-change` злоупотреблений |
| Тень/уплотнение шапки | header | класс при `scrollY > 8` |
| Hover-подъёмы | карточки, кнопки, соцсети | CSS transitions (уже есть, обновить значения) |

**Правила:**
- `@media (prefers-reduced-motion: reduce)` — выключается ВСЁ: reveal, каскад, докрутка (цены показываются сразу финальными), частицы, параллакс, hover-подъёмы, плавный скролл.
- Мобильные (≤900px): частицы и параллакс **отключены**; каскад и докрутка остаются (лёгкие); hover-состояния не критичны (touch).
- Частицы не генерируются, если `matchMedia('(pointer: coarse)')` или узкий экран.

## 7. Мобильная адаптация («идеально»)

Текущие брейкпоинты (900/760/600/360) сохраняются, плюс проверка на 320px.

- **Без горизонтального скролла** на 320–414px (html/body `overflow-x: hidden` уже есть; любые декоративные элементы — только внутри контейнеров или за `overflow: hidden` секции).
- **Touch-цели ≥ 44×44px**: бургер, пункты шторки, кнопки, ссылки карточек контактов.
- **Инпуты ≥ 16px на мобильных** — исключить автозум iOS (сейчас 14px — исправить).
- **Safe-area insets** (`env(safe-area-inset-*)`) для шапки, шторки меню и подвала (iPhone с чёлкой).
- **Шторка меню**: фикс-позиция, оверлей с затемнением, скролл внутри, если пункты не влезают по высоте.
- **Телефон в контактах/подвале** — не переносится некрасиво: `white-space: nowrap` где уместно, `word-break` только для адреса.
- **Заголовки**: clamp уже есть; с New Standard (400) проверить межбуквенную разрядку на 320px — при необходимости уменьшить `letter-spacing`.
- **Проверка скриншотами** на 320/360/375/414/768/1024/1440 (инструментарий Playwright, как в текущем процессе; скриншоты в `preview/`).
- Шапка на мобильных: `backdrop-filter` работает в iOS Safari 9+ с префиксом `-webkit-` — добавить оба свойства.

## 8. Доступность (сохранить и усилить)

- Контраст ≥ AA: тёмный текст на кремовом/золотом, белый/золото-текст на бирюзовом (проверить `#D1AB56` на `#07574E` — самая светлая точка градиента).
- Фокус-кольца: `--teal-deep` на светлых поверхностях, белое на тёмных (уже есть); проверить кольца на новых кремовых секциях.
- Семантика, `alt`, `aria-live` для ошибок формы, `aria-expanded`/`inert` для меню — без изменений.
- `font-display: swap` — текст виден сразу системным серифом, шрифт дорисовывается.

## 9. Что НЕ меняется

- Содержание всех текстов, прайс (дословно), адрес, телефон.
- `js/booking.js` (CONFIG, сборка сообщения, wa.me) и логика формы в `js/main.js` — функции остаются, добавляются только анимационные модули.
- Структура `index.html` — правки минимальны: подключение шрифтов (убрать Playfair), при необходимости пара классов/контейнеров для частиц и листа.
- SEO-меты, favicon, якорная навигация.

## 10. Технические детали

- **Файлы:** `css/style.css` — переписывается начисто в структурированном виде (токены → сброс/база → общие компоненты → секции → анимации → адаптив), все существующие правила сохраняются и обновляются; `js/main.js` — модули: счётчик цен, каскад, частицы, параллакс, тень шапки; `index.html` — шрифты, контейнер частиц; `fonts/newstandard.otf` — переместить из корня.
- Без сборщиков и зависимостей; сайт по-прежнему открывается двойным кликом, шрифт загружается локально (сайт работает офлайн, кроме Great Vibes/Montserrat).
- JS-модули пишутся в стиле существующего `main.js` (IIFE, `var`, без транспиляции) и не ломаются при отсутствии элементов (защитные проверки).
- Существующие тесты `tests/booking.test.mjs` должны проходить без изменений (логика формы не трогается).

## 11. Критерии приёмки

1. Скриншоты на 320/360/375/414/768/1024/1440: нет горизонтального скролла, ничего не обрезано, шапка/шторка/подвал корректны.
2. Дизайн соответствует §5 (кремовая шапка и контакты, двойные рамки, градиенты).
3. Анимации работают на десктопе (частицы, параллакс, каскад, докрутка, hover); на мобильных частицы/параллакс отключены; при `prefers-reduced-motion` всё статично.
4. Шрифт New Standard загружается из `fonts/`, кириллица отображается; «₽» виден в ценах (из Georgia).
5. Контраст AA; фокус-кольца видимы на всех фонах.
6. Форма записи → WhatsApp работает как раньше; `booking.test.mjs` проходит.
7. Изменённые файлы закоммичены; `fonts/newstandard.otf` в git.
