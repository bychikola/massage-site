# Редизайн «Утончённая элегантность» — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Освежить дизайн сайта «Массаж лица и тела» в направлении A (кремовая шапка и контакты, градиенты, двойные рамки, богатые анимации, шрифт New Standard) с безупречной мобильной адаптацией.

**Architecture:** Статический сайт без сборщиков. `css/style.css` переписывается начисто по секциям (токены → база → шапка → hero → услуги → обо мне → запись → контакты → подвал → движение), каждый таск обновляет свою часть. Логика эффектов выносится в новый тестируемый модуль `js/motion.js` (чистые функции, UMD как `js/booking.js`); DOM-обвязка — в `js/main.js`. Визуальная приёмка — Playwright-тесты (скриншоты + проверка горизонтального скролла + шторка + форма).

**Tech Stack:** HTML, CSS, ванильный JS (var-стиль, как в существующем коде), Node 24 (`node --test`), Playwright (devDependency) для визуальных проверок, локальный OTF-шрифт.

## Global Constraints

- Сайт открывается двойным кликом по `index.html` (file://), без сервера и сборщиков.
- Контент, прайс (дословно), адрес `с. Чикола, ул. А. Макоева, д. 10`, телефон `+7 928 483-91-14` — НЕ менять.
- `js/booking.js` и логика формы → WhatsApp не трогаются; `tests/booking.test.mjs` всегда зелёный.
- Заголовки: `font-weight: 400`, `font-synthesis: none` (в New Standard нет жирных начертаний — без синтетического жирного). Стек: `"New Standard", Georgia, "Times New Roman", serif`; «₽» берётся из Georgia автоматически.
- Палитра: золото `#CFAC58`, золото-текст `#D1AB56`, золото-глубокий `#C9A654`, бирюза `#044E47`, бирюза-глубже `#033631`, крем `#FAF6EC`, текст `#0A3F3A`.
- Анимации только на transform/opacity (плюс цвет/тень/фон на hover). `prefers-reduced-motion: reduce` выключает ВСЁ.
- На экранах ≤900px частицы и параллакс отключены; на тач-устройствах частиц нет.
- Без горизонтального скролла на 320–1440px. Тач-цели ≥44×44px. Инпуты ≥16px на мобильных (автозум iOS). Safe-area insets для шторки/подвала/контейнера.
- Контраст текста ≥ AA; фокус-кольца видны на всех фонах (тёмно-бирюзовое на светлом/золотом, белое на тёмном).
- JS в стиле существующего `main.js`: IIFE, `var`, защитные проверки на отсутствие элементов.
- Коммиты после каждого таска, стиль сообщений как в истории (`feat:`/`fix:`/`chore:`).

```js
/* ============================================================
   Чистые функции системы движения (редизайн).
   Без DOM — тестируются в Node. Стиль: UMD, как booking.js.
   ============================================================ */
(function (global) {
  "use strict";

  var DESKTOP_MIN_WIDTH = 901;
  var PARTICLES_DESKTOP = 7;
  var PARALLAX_LIMIT_PX = 80;

  function effectsConfig(opts) {
    var o = opts || {};
    var reducedMotion = !!o.reducedMotion;
    var coarsePointer = !!o.coarsePointer;
    var viewportWidth = typeof o.viewportWidth === "number" ? o.viewportWidth : 0;
    var desktop = viewportWidth >= DESKTOP_MIN_WIDTH;
    return {
      particles: !reducedMotion && desktop && !coarsePointer,
      parallax: !reducedMotion && desktop,
      stagger: !reducedMotion,
      countUp: !reducedMotion
    };
  }

  function staggerDelayMs(index, baseMs, capMs) {
    var base = typeof baseMs === "number" ? baseMs : 60;
    var cap = typeof capMs === "number" ? capMs : 500;
    var i = Math.max(0, Number(index) || 0);
    return Math.min(i * base, cap);
  }

  function easedProgress(p) {
    var t = Math.max(0, Math.min(1, Number(p) || 0));
    return 1 - Math.pow(1 - t, 3);
  }

  function particleCountFor(viewportWidth) {
    return viewportWidth >= DESKTOP_MIN_WIDTH ? PARTICLES_DESKTOP : 0;
  }

  function parallaxShiftPx(scrollY, factor) {
    var f = typeof factor === "number" ? factor : 0.2;
    var shift = scrollY * f;
    return Math.max(-PARALLAX_LIMIT_PX, Math.min(PARALLAX_LIMIT_PX, shift));
  }

  var Motion = {
    DESKTOP_MIN_WIDTH: DESKTOP_MIN_WIDTH,
    effectsConfig: effectsConfig,
    staggerDelayMs: staggerDelayMs,
    easedProgress: easedProgress,
    particleCountFor: particleCountFor,
    parallaxShiftPx: parallaxShiftPx
  };
```
